5A Offline Persistence:

5B Background Sync:

Pushes record to Supabase DB and flips is_synced = true.

Figure 07 : State Machine: Offline-First Synchronization

● Initial State: App Launch
State: Idle / Waiting for Action
▼ Action: User Logs Meal or Hydration
Check: Is Internet Network Online?
✓ ONLINE PATH
1. Write to SQLite (is_synced = true)
2. Direct POST to Supabase Database
3. Live Dashboard Updates Instantly
✗ OFFLINE PATH
1. Write to SQLite (is_synced = false)
2. Show Offline Saved Banner
3. Connectivity Stream: Push on Reconnect
● Final State: Synchronized with Cloud
Figure 7: State Machine - Offline-First Sync. State transitions handling network interruptions, SQLite queues, and auto-sync.

Figure 09 : AI Workout Plan Sequence Diagram

1 User Trigger: User clicks "Generate Workout Plan" on Workout tab.
2 Backend Query: Fetches user age, weight, target fitness goal, and medical restrictions (e.g., Hypertension, PCOS, Diabetes) from Supabase.
3 AI Plan Generation: Gemini LLM synthesizes a weekly schedule containing custom warm-ups, specific exercises (sets, reps, rest, safety cues), and cool-downs matching the clinical profile.
4 Database & Cache Storage: Workout schema saved to Supabase Cloud and cached locally in SQLite.
5 Execution Logging: User checks off completed exercises. Flutter triggers toggleExerciseCompletion locally and updates Supabase.
✓ Workout Screen Rendered with Interactive Progress & Safety Advisories
Figure 9: AI Workout Plan Sequence & Execution Flowchart. Visualizes how profile details are retrieved, processed by Gemini, stored, and updated interactively during exercise execution.

Figure 10 : Predictive AI Coaching & Recommended Swaps Data Flow

1 Data Aggregation: SyncService pushes local meal logs to Cloud DB.
2 Habit Scoring Engine: FastAPI `/coaching/habit-score/{user_id}` computes 7-day intake metrics (macro balances, timing consistency).
3 Food Swap Analyzer: POST request sent to `/coaching/food-swaps` sending today's meals. Gemini evaluates dietary targets.
Healthy Swaps Needed?
✓ Yes

Gemini proposes healthy alternatives (e.g., whole grains instead of white rice) and explains the clinical reason.

✗ No

Displays "No swaps needed yet today" message. Encourages user to maintain high score.

✓ Render AI Coaching Panel with Habit Score, 7-Day Trend Chart & Swaps
